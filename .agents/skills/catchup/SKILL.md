# 세션 캐치업 (catchup)

새 세션을 시작했을 때, 흩어진 문서와 git 기록을 모아 "지금 어디까지 왔고 다음에 뭘 할지"를 한눈에 정리한다.
목적은 **요약**이지 작업 실행이 아니다 — 파악만 하고, 실제 작업은 사용자 지시를 기다린다.

## 1. 읽기 (이 순서대로)
- `AGENTS.md` — 프로젝트 개요, 기술 스택, "구현 단계 현황" 표의 Phase 상태.
- `PROGRESS.md` — 맨 아래 최근 날짜 섹션 위주로. "다음 작업"이 적혀 있으면 그대로 살린다.
- `git log` 최근 커밋 5~10개 + `git status` — PROGRESS의 마지막 기록 이후 실제로 뭐가 바뀌었는지 대조한다.
- 오늘 날짜를 절대 날짜(YYYY-MM-DD)로 확정하고, PROGRESS 마지막 기록과 며칠 차이인지 인지한다.

## 2. 대조 (문서 vs 실제)
- PROGRESS의 "다음 작업" 항목이 이미 git에 반영됐는지 확인한다 — 했는데 문서에 안 적힌 게 있으면 짚어준다.
- 반대로 문서엔 완료로 돼 있는데 커밋이 없으면(또는 미커밋 변경이 떠 있으면) 그것도 알려준다.

## 3. 보고 (간결하게)
아래 3덩어리로 정리한다. 장황하게 늘이지 말 것.
- **현재 상태** — 완료된 Phase / 진행 중인 것 한 줄씩.
- **남은 일** — PROGRESS의 "다음 작업" + 미해결 TODO(특히 보안·배포 같은 필수 항목은 강조).
- **시작 제안** — "무슨 작업부터 할까?"로 끝내고 사용자 지시를 기다린다. 임의로 코드 수정에 착수하지 않는다.

## 주의
- 이 스킬은 읽기·요약 전용이다. 파일을 고치거나 커밋하지 않는다.
- 문서를 갱신할 때가 됐으면 그건 `sync-docs` 스킬 소관이라고 안내만 한다.
